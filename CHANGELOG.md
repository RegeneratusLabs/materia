# Changelog

## 1.0.0 — 2026-11-06

First local product release.

- Cited recommendation engine: 23 patterns / 30 options (10 supplement-herb, 5 lifestyle, 15 referral).
- 400-document, 5,143-chunk licence-clear corpus.
- Lab review → interpretation → Plan → grounded chat → clinician review.
- Critical-value gate (adult and newborn), medication flags, lab-derived kidney/liver/bleeding safety.
- CPU-only chat: MiniCPM5-2B Q4 (1.5 GB) and Q8 (2.7 GB), no GPU.
- Default synthetic nutrient/lipid sample; amino-acid coverage-gap demo.
- 162 tests, 72/72 contract checks, 28/28 single-turn and 17/17 multi-turn chat contracts.
- Review packet, web review mode, CLI, CSV import/export, rule audit and validation dossier.
- Self-contained `release/materia-1.0.0-local.tar.gz`.
