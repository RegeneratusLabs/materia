Why the shapes are split this way

  • Models read and draft. Language-shaped work, where being wrong is recoverable because a human reads it next.
  • Code decides and gates. Numbers, units, ranges, contraindications — anything where a plausible-sounding mistake is expensive.
  • Memory is per phase, not total. Ingest peaks at 3.2 GB, query at 2.8 GB. Three models, never all resident.
  • The corpus is the product. Everything above it is plumbing; every capability claim lives or dies on what is in that index.
